The release the enterprise plan has owed since `1.1` — displaced five times by audits that
outranked it, shipped at last — plus the three decisions the 2026-08-23 sweep left open, all
ruled and closed. Conformance pins contracts; from this release, **quality and adversarial
resistance are pinned the same way**, and the same definition runs as a service.

## Quality is certified (`Standard.Agents.Evals`)

A deterministic golden-case runner measuring what the plan named: **task completion,
groundedness, retrieval precision and recall, tool selection, refusal correctness, and
revision effectiveness** — thresholded, CI-gated beside conformance, no keys, no network.

The composition under evaluation is the real one: knowledge served by the real ranked
retrieval, tools through the real perimeter, refusal judged from the run's actual
`AgentOutcome.Status`. The honesty rules carry over from the conformance harness: a metric is
computed only where a case supplies its golden data, **a threshold that binds nothing is an
error**, a typo'd field fails loudly — and every metric was **proven able to fail** before
being trusted to pass, from a wrong golden fact to an always-refusing gate (caught at 0.50 by
the benign half, which is why refusal is measured in both directions). Every report carries
the framework version and the golden-set hash, because a score nobody can attribute is a
score nobody can investigate. Point the runner at your own golden set and it answers the
question that matters when anything changes: *did v4 of this skillset make the agent worse?*

## Adversarial evaluation is certified — and Critical requires it

Three attacks the suite never covered, each with the Brain scripted as **fooled**, because
the defense under certification is never the model's judgment — it is that a fooled model
still cannot act outside the perimeter:

- **A poisoned knowledge passage** orders exfiltration; the Brain obeys; the allow-list holds.
- **A poisoned memory** rides the seam a remembered preference would; data can never grant
  what policy did not.
- **A fooled Brain cannot cross tenants**: the permitted scope executes, the other tenant's
  is denied, and the run recovers to finish its legitimate half.

Each vector asserts the poison **reached** the Brain, so a pass means the attack was
delivered and survived — not dodged. Each was proven able to fail by removing the very
control it certifies. The Critical profile now **requires** all three, and its description
says *adversarial evaluation* again — words it lost mid-release when nothing verified them,
back because something does.

## The same definition as a service (`Standard.Agents.Host`)

The exposure layer as The Standard defines one: controllers that are pure mapping over one
`IAgent` dependency, a heartbeat with no security and no claims, SSE streaming whose
`Response` events equal the batched answer, and zero-config startup that stands and says what
to configure. Closing the connection cancels the run at its next turn boundary — and, through
the nesting seam, any sub-agents it started. **Nothing was added to the builder**: five lines
on a laptop, the same five lines behind HTTP.

## The three open decisions, ruled and closed

- **A turn-capped run delivers no answer — and says so.** It used to hand back the last
  tool's raw output as the answer and record it into the session, so the next prompt was told
  the agent said something it never said. The cap now tells the same truth the budget stop
  tells: prose about why, a `Status` event, no session write. The one Skipped test in the
  suite — the sweep's standing demonstration — now runs and passes.
- **Direction counts its dependencies honestly.** Eight constructor parameters, three of them
  delegates that participated in authorization invisibly, now travel as one `PerimeterPolicy`
  datum — policy is Data — and a new tier rule bans naked delegates in every service
  constructor, closing the general escape the sweep demonstrated.
- **Cancellation crosses the nesting seam.** `AgentRun` carries the run's token the way it
  carries the run's identity, and `AgentTool` hands it to the nested agent through the new
  stoppable `IAgent.RunAsync(prompt, cancellationToken)` — cancelling an outer run stops the
  whole tree. Proven with a nested run that used to execute its tool fifty times after
  cancellation, and now executes it once.

## Enterprise groundwork that rode along

The package multi-targets **net8.0 and net10.0** with the full suite green on each, so the
LTS estates that could not reference it now can — and a key, an audit chain, or a session
file written on one target reads identically on the other. The public surface is declared in
`PublicAPI.Shipped.txt` and guarded by the build, so a Standard Versioning segment change is
a visible diff rather than a discipline. The supply chain is watched between builds —
Dependabot and CodeQL — and the repository states how it is contributed to, secured, and
conducted (`CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`).

## Compatibility

New public routines (`IAgent.RunAsync(prompt, cancellationToken)` as a default interface
member, its `StandardAgent` overload, `AgentRun.CancellationToken`), one new model
(`PerimeterPolicy`), and two new projects that touch the core not at all. One internal-shape
change: `DirectionCoordinationService`'s constructor takes the policy datum —
`docs/support.md` has always said service constructors are not a public contract. **No
contract removed, no field repurposed** — nothing written against `1.6.1` needs to move.
