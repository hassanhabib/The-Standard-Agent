The release where the agent stopped being alone. Other agents are now a capability like every
other — reached three ways, governed by the same perimeter, declared as data — and a run can be
handed to a specialist without the answer ever being rewritten on the way back.

## The fleet, three ways

`.Agents("Fleet")` points at a folder where **every `.json` file is an agent** — the same
documents `FromJson` composes, so the file *is* the agent: its `name` is what a handoff calls
(the file's own name when absent), its `description` is the advertisement. `.UseAgents(...)`
takes a provider's registry broker; `.OnAgents(...)` lets your code decide the fleet per
composition. Registries accumulate, and the first source to claim a name keeps it — the rule
MCP servers already live by, and a registry can never shadow a tool the host wired in code.

## One decision buys everything

A registered agent **materializes as a tool**. That single decision means the fleet inherits
every control that already governs acts, with no second code path: advertisement under the
description opt-in in `{{tools}}`, allow-lists that can forbid a handoff, approvals that can
put a human before one, the decision log, telemetry, and cancellation across the seam.

## Three flavors of multi-agent flow

**Sub-agent** — `ACTION: billing: <task>`: the specialist's answer returns as an observation
for the outer brain to synthesize. The handoff is **grounded by default** — *"The user asked:
{prompt} — Your task: {input}"* — the task plus just enough context to do it, and a custom
template decides exactly what crosses, which is the whole configurability of a handoff.

**Transfer** — `TRANSFER: billing`: the outer brain recognizes the whole prompt belongs to a
specialist, and the specialist's answer **is** the run's answer, verbatim — no synthesis turn.
The honesty rule that makes terminal handoffs safe: a specialist that was refused, held, or
failed comes back as a marked `[did not complete]` observation and the loop keeps working —
a refusal is never presented as the user's answer. The transfer rides the same act pipeline
as everything else, so the perimeter rules first.

**Chain** — a deterministic sequence is your code calling agents in order, where determinism
belongs; every link keeps its own guardians, budget and perimeter.

## The fleet is data

```json
{ "agents": [ "Fleet", { "name": "billing", "description": "Handles refunds.", "maxTurns": 3 } ] }
```

A member is a folder path or an inline agent document — identity included. A nameless inline
member refuses to compose, naming what is missing: a handoff calls agents by name, and a
nameless agent is one the brain could never call.
